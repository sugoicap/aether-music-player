# PulsePlayer

A minimalist Android music player for your local music and online radio.
Egy letisztult Android zenelejátszó helyi zenékhez és online rádióhoz.

## Features / Funkciók

- Local music library with sub menus: Artists, Albums, Folders, All songs
- One search for every sub menu
- Online radio (Radio Browser directory): Favorites, Countries, Languages, All, each with search
- Now Playing screen with waveform seek bar, shuffle, repeat, previous/next
- Three layouts: Classic, Minimal, Vinyl
- Album-art based or custom accent color, OLED true-black theme, blurred cover background
- Grid, compact and detailed list views with FLAC/MP3 and bitrate badges
- Background playback with notification controls
- Hungarian and English language

## Install / Telepítés

1. Open the **Releases** page and download the latest `.apk`.
2. Open the file on your phone and allow installing from unknown sources when asked.
3. Requires Android 8.0 or newer.

## Build

The APK is built automatically by GitHub Actions (`.github/workflows/build.yml`).
